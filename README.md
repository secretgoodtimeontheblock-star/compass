# Compass

Лёгкий десктопный помощник трейдера: **акции МосБиржи** и **крипта** в одном приложении.
Графики, сигналы, бэктест, журнал сделок, AI-разбор. **Автоторговли нет** — приложение
не размещает ордера и не принимает торговых ключей.

> Не инвестиционная рекомендация. Сигналы — инструмент анализа, решение и риск за вами.

## Статус

Этап 0 (данные): адаптеры МосБиржи и крипты, кэш свечей в SQLite, вотчлист, локальный API.
Стратегии, бэктест, сигналы, интерфейс, AI — следующие этапы, см. [docs/PLAN.md](docs/PLAN.md).

## Запуск (разработка)

```bash
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python -m compass          # API на http://127.0.0.1:8765/docs
.venv\Scripts\python -m pytest
```

Данные пользователя (кэш, вотчлист) — `%APPDATA%\Compass\compass.sqlite3`
(переопределяется `COMPASS_DATA_DIR`).

## Источники данных и ограничения

- **МосБиржа** — открытый ISS API. Бесплатные котировки идут с задержкой ~15 минут:
  для дней и недель неважно, для интрадея важно.
- **Крипта** — публичные данные через ccxt, ключи не нужны. Биржа по умолчанию — OKX
  (`COMPASS_CRYPTO_EXCHANGE`). На проверке из РФ Bybit отвечал 403, Binance — 451;
  если нужна такая площадка — задайте прокси в `COMPASS_PROXY`.
