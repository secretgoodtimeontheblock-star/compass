# Compass

Лёгкий десктопный помощник трейдера: **акции МосБиржи** и **крипта** в одном приложении.
Графики, сигналы, бэктест, журнал сделок, AI-разбор. **Автоторговли нет** — приложение
не размещает ордера и не принимает торговых ключей.

> Не инвестиционная рекомендация. Сигналы — инструмент анализа, решение и риск за вами.

## Статус

Готово (этапы 0–2): данные МосБиржи и крипты, кэш свечей, три стратегии (пересечение
средних, RSI, пробой канала), бэктест, поиск сигналов по расписанию, риск-калькулятор,
Telegram-уведомления, журнал сделок и интерфейс: график со свечами, объёмом, SMA и
маркерами сигналов/своих сделок, избранное, лента сигналов, проверка стратегий с кривой
капитала, журнал, тёмная/светлая тема. AI — следующий этап, см. [docs/PLAN.md](docs/PLAN.md).

## Как это работает

- **Сигнал** — смена позиции стратегии на последней *закрытой* свече (вход или выход).
  Незакрытая свеча игнорируется, повторный скан не дублирует сигналы.
  Для дневных свечей это значит: сигнал приходит после закрытия суток (полночь UTC у
  крипты, полночь МСК у акций), а не сразу после закрытия торгов.
- **Бэктест** — решение на закрытии свечи, сделка по открытию следующей, с комиссией и
  проскальзыванием. Только long, без плеча, все деньги в сделку, **без стоп-лоссов**.
  Хороший бэктест не гарантирует прибыль: он показывает, как правило работало на
  прошлых данных.
- **Стоп** в сигнале — ориентир «цена − 2·ATR(14)», нужен для расчёта размера позиции.
  В бэктесте он не участвует.
- **Размер позиции** считает код по формуле «потеря при стопе ≤ N% капитала» с учётом
  лота (акции) или шага количества (крипта).
- **Telegram:** `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в окружении; без них уведомления
  идут в лог (dry-run). Токен в логи не попадает.

## Запуск (разработка)

```bash
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -e ".[desktop,dev]"

# интерфейс (Node 22, pnpm): собирается прямо в src/compass/static
cd ui && pnpm install && pnpm build && cd ..

.venv\Scripts\python -m compass.desktop   # нативное окно (pywebview / WebView2)
.venv\Scripts\python -m compass           # только движок: http://127.0.0.1:8765
.venv\Scripts\python -m pytest            # тесты движка
cd ui && pnpm test                        # тесты интерфейса
```

Разработка интерфейса с горячей перезагрузкой: движок (`python -m compass`) на :8765 и
`cd ui && pnpm dev` (Vite на :5173 проксирует `/api` на движок).

Данные пользователя (кэш, вотчлист) — `%APPDATA%\Compass\compass.sqlite3`
(переопределяется `COMPASS_DATA_DIR`).

## Источники данных и ограничения

- **МосБиржа** — открытый ISS API. Бесплатные котировки идут с задержкой ~15 минут:
  для дней и недель неважно, для интрадея важно.
- **Крипта** — публичные данные через ccxt, ключи не нужны. Биржа по умолчанию — OKX
  (`COMPASS_CRYPTO_EXCHANGE`). На проверке из РФ Bybit отвечал 403, Binance — 451;
  если нужна такая площадка — задайте прокси в `COMPASS_PROXY`.
